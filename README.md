# De-Influencer SMS

## Goal

Help people second-guess impulse buys by SMS: they text the app (via **Twilio**), optionally send a **photo** of something they might buy, and get back a short, humorous **de-influencer** style roast generated by **Google Gemini**—plus a practical nudge (borrow or rent).

## Stack

- [Next.js](https://nextjs.org/) 14 (App Router)
- [Google Generative AI](https://ai.google.dev/) (`gemini-2.5-flash`) for vision + text
- [Twilio](https://www.twilio.com/) for inbound SMS (webhook expects Twilio-style form posts and returns TwiML)

## Setup

```bash
npm install
```

Create **`.env.local`** in the project root (next to `package.json`). This file is gitignored—do not commit secrets.

```bash
GEMINI_API_KEY=your_key_here
```

Get a key from [Google AI Studio](https://aistudio.google.com/).

### Environment variables

| Variable | Required | Purpose |
| --- | --- | --- |
| `GEMINI_API_KEY` | yes | Gemini calls |
| `TWILIO_AUTH_TOKEN` | yes in production | Verifies `X-Twilio-Signature` on every webhook POST. Missing token = 500. |
| `TWILIO_ACCOUNT_SID` | recommended | Used to fetch Twilio-hosted MMS media with basic auth |
| `PUBLIC_WEBHOOK_URL` | recommended | Exact public URL Twilio posts to, e.g. `https://…/api/webhook`. Used for signature checks. |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | yes for beta | Shared store for opt-in status and the daily cap. (`KV_REST_API_URL` / `KV_REST_API_TOKEN` also work.) Without them the app falls back to in-memory state, which is **not** reliable on Vercel. |
| `DAILY_MESSAGE_CAP` | no | Max messages processed per UTC day. Default **50**. Over the cap the webhook sends no reply. |
| `PAUSE_REPLIES` | no | Set to `1` to stop all replies (kill switch). STOP is still honored. |
| `HEALTH_CHECK_TOKEN` | no | Required to call `/api/health/gemini` in production. Send as `Authorization: Bearer <token>`. |
| `TWILIO_SKIP_SIGNATURE_CHECK` | no | Set to `1` for local curl testing only. Ignored when `NODE_ENV=production`. |

## Opt-in flow

Matches the copy on `/sms`:

- A new number gets "Text START to sign up" and no roast until it texts **START**.
- **STOP** (also STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT) unsubscribes. The webhook sends no reply and ignores later messages until the number texts **START** again.
- **HELP** (or INFO) returns the help text.

## Run locally

```bash
npm run dev
```

Open the URL Next prints. Examples below use **`http://localhost:3004`**; if your terminal shows a different port (3000, 3001, etc.), use **that** port everywhere—`curl`, `cloudflared`, and mental checks must match.

## Check Gemini

With the dev server running:

```bash
curl -sS http://localhost:3004/api/health/gemini
```

A working key returns JSON with `"ok": true`.

## Test the SMS webhook (no Twilio required)

The webhook accepts `application/x-www-form-urlencoded` body fields like Twilio sends (`From`, `Body`, optional `MediaUrl0`). For local curl, add `TWILIO_SKIP_SIGNATURE_CHECK=1` to `.env.local`, and send `Body=START` first so the number is opted in. Example with a public test image:

```bash
curl -X POST http://localhost:3004/api/webhook \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "From=+15551234567" \
  -d "To=+15557654321" \
  -d "MediaUrl0=https://images.unsplash.com/photo-1526170375885-4d8ecf77b99f?auto=format&fit=crop&w=800&q=60"
```

Response is **TwiML** XML with a `<Message>` body. Omit `MediaUrl0` to exercise text-only conversation mode for that `From` number.

## Expose localhost for Twilio (cloudflared)

Twilio needs a **public HTTPS** URL to POST webhooks. For local dev, use [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) (`cloudflared`)—no ngrok required.

1. Install (macOS):

   ```bash
   brew install cloudflared
   ```

2. Start Next.js (`npm run dev`) and note the port (this project’s examples assume **3004**).

3. In another terminal, run a **quick tunnel** to that port:

   ```bash
   cloudflared tunnel --url http://localhost:3004
   ```

   The port here must match whatever Next printed (e.g. `Local: http://localhost:3004`).

4. `cloudflared` prints a **trycloudflare.com** HTTPS URL. In **Twilio Console → Phone Numbers → your number → Messaging**, set **A message comes in** to **Webhook** (HTTP POST) and use:

   `https://<your-subdomain>.trycloudflare.com/api/webhook`

5. Save in Twilio. Send an SMS to your Twilio number to test.

Quick tunnels get a **new URL each time** you restart `cloudflared`; update Twilio when it changes. For a stable hostname, set up a [named tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/get-started/create-local-tunnel/) in the Cloudflare dashboard.

## Twilio in production

Point your Twilio phone number’s **Messaging webhook** to your deployed URL, e.g. `https://your-domain.com/api/webhook` (POST). Set the same **`GEMINI_API_KEY`** in your host’s environment variables (e.g. Vercel project settings), not in the repo.
